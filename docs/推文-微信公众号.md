# OESP 刷飞牛，风扇这事终于不用管了

OESP（OES Plus）刷了飞牛 fnOS 之后，风扇怎么管一直挺麻烦：要么一直转太吵，要么一直不转又怕热。

现在装一个应用就能解决。它叫 **oesp-fanctl**，一个给飞牛写的原生风扇管理应用。

装完自动接管风扇，按温度自己转；网页上点几下就能调，命令行也能看。不用改配置文件，不用敲命令，也不用手动挂服务。

## 一、它能干什么

一句话：把 OESP 的风扇交给你管。

- **网页一键控制** —— 飞牛桌面点图标就能打开，温度、曲线、模式全在一块页面上
- **三种运行模式** —— 自动温控 / 常开 / 常关，点一下即刻切换
- **实时温度曲线** —— CPU、GPU、每块硬盘分开画，带 12 小时历史
- **命令行工具** —— 内置 `oesp-fanctl` 和 `fanlog`，SSH 里一条命令看全部
- **过温兜底保护** —— 温度冲到紧急线就强制开风扇，不受当前模式限制

下面逐条说。

## 二、网页上点一下，风扇就听你的

打开飞牛桌面上的「OESP风扇助手」图标，就是监控页。顶上三个模式按钮：

- **自动温控**（默认）—— 温度到了开，降下来关，最省电也最安静
- **常开** —— 风扇一直转，不看温度。夏天、硬盘多、或者就想让它一直转
- **常关** —— 风扇一直停。晚上嫌吵就切过去

**点一下按钮就生效，不用再点保存，也不用重启。**

## 三、温度看得见

页面上把所有温度都摆出来：CPU、GPU 实时温度，每块硬盘的温度，还有 12 小时历史曲线，一眼看出温度怎么走。

温度阈值也能直接在网页上改：CPU 几度开、几度关，硬盘几度通风，改完立刻生效。

顺带说一句，OESP 内置风扇是二态开关风扇，只有「开」和「关」两种状态，不支持调速。这是硬件决定的，任何软件都改不了。

## 四、SSH 党也有工具

不想开网页？装完之后命令行直接能用：

```bash
oesp-fanctl status           # 看当前状态
oesp-fanctl mode on          # 切常开
oesp-fanctl set TEMP_ON 40   # 改开风扇的温度
fanlog                       # 实时温度监控
```

安装时已经自动建好软链接，不用自己配环境变量。

`fanlog` 会像这样实时刷温度：

```
[13:24:21] 温度=38.2℃ GPU=39.1℃ 硬盘=31℃ 风扇=1 模式=自动
```

比翻日志文件直观得多。

## 五、这一版比上一版强在哪

**1. 网页切换模式，点一下立刻生效**

以前切模式还要再点一次「保存」，现在点完按钮就生效，2 秒内风扇状态跟着变。

**2. 新增两个命令行工具**

`oesp-fanctl` 和 `fanlog` 装完即用，安装时自动建好软链接。以前只能翻日志文件，现在一条命令直接刷温度。

**3. 参数写错会被拦下**

网页和命令行都加了校验。比如把「开风扇温度」设得比「关风扇温度」还低，会直接拒绝并给出提示，不会把配置写坏。命令行改错还会自动回滚。

**4. 修掉了重复进程的问题**

以前反复重启可能留下多个网页进程，现在每次启动前会自动清理，只保留一个。

**5. 状态里显示的访问地址终于对了**

`status` 现在会告诉你从哪里进网页，不再是那个点不开的假地址。

## 六、怎么装

1. 下载 `oesp-fanctl_1.15_arm.fpk`
2. 飞牛应用中心 → 手动安装 → 选这个文件
3. 装完什么都不用配

安装过程会自动：卸载内核里抢控制权的风扇驱动、从设备树读引脚号、停掉冲突服务、启动温控守护进程。

**风扇立刻按温度自动启停。**

## 七、怎么卸

应用中心卸载就行。会自动恢复系统原本的风扇控制方式，不留尾巴。

装得不满意，卸掉就回到原样。

## 写在最后

默认阈值是 38℃ 开 / 35℃ 关，嫌吵可以把阈值调高一点，或者直接切「常关」。
